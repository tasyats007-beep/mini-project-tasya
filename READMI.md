# Product Information System

## 📌 Deskripsi
Product Information System adalah mini project untuk mata kuliah Pemrograman Web yang digunakan untuk mengelola dan menampilkan informasi produk.

Project ini dibuat menggunakan PHP sederhana dengan konsep pemisahan antara data, proses, dan tampilan.

## 🎯 Tujuan
- Menyimpan data produk dalam bentuk array.
- Menghitung nilai stok setiap produk.
- Menghitung total nilai aset stok.
- Menampilkan informasi produk dalam bentuk tabel.
- Memberikan tanda jika stok produk berada dalam kondisi kritis.
